## 0. 系统总览（现状）

- 两端结构：`insp-*` 7 个技能被打包成 zip 导入 SciencePal 云端沙箱；`platform/` 是本机侧（安装、收货员、评价页、观察、周报、立刻动手、状态发布）。`README.md:88-98`、`docs/开发文档.md:44`。
- 主链路：`prepare`（抓 arXiv / 观察 / 去重 / 打分）→ `insp-card` 写卡 → `finalize` 校验裁剪并打印 `<<<INSP_BUNDLE_JSON … >>>` 结果块 → 本机 `receiver.py` 收货入库 → 评价页 `127.0.0.1:8765` → `verdicts.jsonl` → 权重 / 周报 / 负面清单。`README.md:40-59`、`insp-nightly/scripts/insp_run.py:241-258`。
- 无数据库、无 ORM、无消息队列：所有状态是 `json / jsonl / md / zip / 目录` 文件 + 平台 API / 记忆。跨进程协作靠文件锁、目录轮询、本机 HTTP、stdout 结果块。
- 代码风格：无 pytest/unittest 框架，全部是脚本式回归（`main()` + 断言 + 退出码），统一由 `scripts/selfcheck.py:252-276` 的 22 个套件汇总。
